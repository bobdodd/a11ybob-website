# Decision log

Running record of meaningful technical, design, and accessibility decisions made
while building a11ybob.com. Source material for the public `/colophon` page and
for any "how this site is built" articles.

One file per decision, numbered. Each file: what was chosen, what was rejected,
why, and any accessibility implications. Short is fine — the goal is a record,
not an essay.

Entries are append-only. If a decision is later reversed, write a new entry that
supersedes the old one rather than editing the old one.
