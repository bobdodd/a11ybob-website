7. Menu and Menuitem (role="menu", role="menuitem")

These tests validate accessible names for elements with menu-related ARIA roles.

Warning Examples - Menu

Menu with aria-label (Use with Caution)

This div with role="menu" has an aria-label attribute that serves as its accessible name. However, role="menu" and role="menuitem" should only be used for application-like interfaces that mimic desktop software menus, not for website navigation. Key ARIA attributes explained:

  • role="tree" - Identifies the widget as a tree view
  • role="treeitem" - Identifies elements as items within the tree
  • role="group" - Contains related treeitems that are children of a parent treeitem
  • aria-expanded="true/false" - Indicates whether a treeitem that has children is expanded or collapsed
  • aria-level="1/2" - Indicates the hierarchical level of each treeitem
  • tabindex="0" - Indicates the currently focused item (only one treeitem has tabindex="0" at a time)
  • tabindex="-1" - Allows items to receive focus programmatically but not in the tab order
